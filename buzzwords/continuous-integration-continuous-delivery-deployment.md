**Continuous Integration / Continuous Delivery-Deployment (CI/CD)**
- Conceptuellement : automatiser le chemin du **commit à la production**.
- Techniquement : la **CI** construit et teste à chaque commit ; le **Continuous Delivery** prépare une livraison prête à déployer sur décision humaine, le **Continuous Deployment** déploie sans intervention.
- Ex : GitHub Actions, GitLab CI/CD, Jenkins.
