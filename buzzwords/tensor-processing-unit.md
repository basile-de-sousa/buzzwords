**Tensor Processing Unit (TPU)**
- Conceptuellement : une puce **conçue par Google** uniquement pour l'**IA**.
- Techniquement : un **ASIC** optimisé pour le **calcul matriciel** (tenseurs), donc moins polyvalent qu'un GPU mais plus **efficace** sur ce calcul-là.
- Sert à : l'**entraînement** et l'**inférence** des grands modèles, accessible uniquement via **Google Cloud**.
- Ex : Google TPU Ironwood, Google TPU Trillium. Équivalents concurrents : AWS Trainium, AWS Inferentia.
