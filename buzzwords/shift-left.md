**Shift-left (ou « shift-left security / testing »)**
- Conceptuellement : déplacer les tests et la sécurité **le plus tôt possible** dans le cycle (vers la gauche du schéma).
- Sert à : trouver les défauts quand ils **coûtent moins cher** à corriger (dans l'IDE ou la PR plutôt qu'en production).
- Ex : SonarQube for IDE, Snyk, GitHub Advanced Security.
