**Web Application and API Protection (WAAP)**
- Conceptuellement : l'**évolution du WAF**, qui protège aussi les **API** (terme Gartner).
- Techniquement : réunit **WAF**, **protection API** (découverte des **shadow API**, schémas), **anti-bot** et **anti-DDoS** couche 7.
- Ex : Cloudflare Application Security, Akamai App & API Protector, Imperva.
